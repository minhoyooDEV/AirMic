AirMic · macOS

轻按 AirPods，掌控麦克风。

AirMic 是免费的开源 Mac 菜单栏应用，旨在通过兼容的 AirPods 耳机柄控件切换默认输入麦克风的静音状态。

如何安装 AirMic

  1. 下载并打开通用 DMG，将 AirMic 拖入 Applications。
  2. 启动应用，允许麦克风访问并连接 AirPods。将要控制的麦克风设为 Mac 默认输入。
  3. 使用已配置的 AirPods 静音手势，或通过小窗口和菜单栏切换静音。正常退出时，应用会尝试恢复原来的麦克风状态。

常见问题

AirPods Pro 可以让 Mac 麦克风静音吗？

需要兼容的 AirPods 静音事件和支持 Core Audio 静音控制的麦克风。原型曾在一台 Apple Silicon Mac 与 AirPods Pro 上测试；当前 Swift 测试版仍待实机验证。

会切换 Zoom 或 Teams 的静音按钮吗？

它只改变当前默认输入设备的静音状态，不控制应用内的静音按钮，也不会让所有连接的麦克风静音。通话应用可能争用 AirPods 控件，请先验证实际环境。

AirMic 会录音吗？

不会。它保持输入音频单元运行以接收控件事件，但不读取、保存、传输或播放麦克风缓冲区。macOS 可能显示麦克风指示器，Bluetooth 播放质量和电池消耗可能受到影响。

为什么 macOS 在启动时要求确认？

此测试版没有 Developer ID 签名或 Apple 公证。对于您信任的应用，请遵循 Apple 的官方打开说明。
